# Submission handoff

Use [WALKTHROUGH.md](WALKTHROUGH.md), [../DX.md](../DX.md), the
[minimal fully-spent lifecycle record](LIVE-LEDGER-CYCLE-2026-09-11.md), its
[machine-readable proof](verification/ledger-paid-lifecycle-2026-09-11.json), and
the earlier [multi-call/refund proof](verification/live-proof-2026-09-11.json).
Together they define the verified testnet flow and its limits. Submission deadlines,
bounty amounts and registry/PR status must be checked against the current official
event/maintainer pages when submitting; this repository does not hardcode them as
live facts.

A narrated video, external submission, GitHub push and public deployment are separate
operator actions. None is implied by the presence of a script, a local report, or
an old screenshot. Do not publish operator tokens, Key Ring profiles, ciphertext
backups, private capability files, or local browser-login URLs.
