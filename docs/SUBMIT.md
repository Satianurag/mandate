# Submission handoff

Use [WALKTHROUGH.md](WALKTHROUGH.md), [../DX.md](../DX.md), and the public
[verification proof](verification/live-proof-2026-09-11.json). They define the
verified testnet flow and its limits. Submission deadlines, bounty amounts and
registry/PR status must be checked against the current official event/maintainer
pages when submitting; this repository does not hardcode them as live facts.

A narrated video, external submission, GitHub push and public deployment are separate
operator actions. None is implied by the presence of a script, a local report, or
an old screenshot. Do not publish operator tokens, Key Ring profiles, ciphertext
backups, private capability files, or local browser-login URLs.
