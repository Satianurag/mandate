# Integration case

Ledger supplies actual hardware funding and Key Ring custody. Mandate adds scoped
execution, a confined consumer, integer reservations, durable recovery, and an
operator interface whose success states follow evidence. This is the primary
integration demonstrated by the live testnet run.

The Graph supplies real testnet Agent0 query data and provenance. Heterogeneous
feedback remains advisory, not a universal trust score. Hedera testnet supplies
consensus anchoring of authenticated event hashes. Claims about paid responses,
merchant revenue and HCS confirmation remain separate and independently inspectable.

Stock x402 supplies batch-settlement primitives. Mandate does not claim to have
invented session delegation, a new payment standard, first-on-chain deployment,
a uniqueness oracle, or unsupported mainnet functionality. Optional treasury,
additional rails, fleets and Substreams experiments are not needed to establish the
core product and are not smuggled into its live verification claim.
